### What I've shipped

| | |
|---|---|
| **Offline ops agent** · *NSWC Corona, NREIP* | Local LLM through llama.cpp, with no cloud, internet, or external APIs. Rust skills (ZeroClaw) for read-only schema-validated DB access, network discovery, SSH switch diagnostics, and ePDU power cycling. Diagnoses downed range equipment by itself and streams its reasoning over WebSockets. The whole appliance rebuilds from a declarative NixOS VM (Docker · PostgreSQL · ChromaDB). Has an offline Whisper voice pipeline with barge-in. |
| **DINA** · *Defense Innovation Navigation Assistant* | Neo4j GraphRAG pipeline for real-time Q&A for Navy and Air Force analysts, **25% more accurate** than baseline RAG. Ran on GCP. I led 4 interns through Agile sprints and briefed DoD stakeholders weekly. |
| [**nl2logic-research**](https://github.com/ghbrando/nl2logic-research) | A verifiable NL → CNL → KIF pipeline that formalizes military doctrine. Code and archive for a 5-paper series on autoformalization in high-assurance domains. |
| [**UniCore**](https://github.com/ghbrando/unicore) · *team project* | Peer-to-peer compute marketplace. Providers rent out idle CPU and RAM, and consumers spin up a Linux VM from the browser with no cloud account, including SSH into machines behind home routers without exposing them. .NET 10 · Blazor · GCP · Docker. |
| [**fod_hunter**](https://github.com/ghbrando/fod_hunter) · *team project* | Edge AI that detects foreign object debris on flight decks. A drone feed goes through YOLOv8 (ONNX) on a .NET vision server, with Whisper voice commands and React operator and deck-crew consoles. |
| **Robotics competition** · *1st place* | Autonomous acquisition robot with PID motor control. Set the competition record at 3,000 pts, 2,000 ahead of second place. |
